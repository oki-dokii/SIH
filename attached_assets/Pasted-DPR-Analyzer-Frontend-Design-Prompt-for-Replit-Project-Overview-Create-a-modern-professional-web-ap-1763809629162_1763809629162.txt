DPR Analyzer Frontend Design Prompt for Replit
Project Overview
Create a modern, professional web application called "DPR Analyzer" - an AI-powered Detailed Project Report analysis platform built with React, TypeScript, and Tailwind CSS.

Design System & Colors
Primary Color: Bright Blue (#200 85% 52%) - Used for main buttons, headlines, borders, and interactive elements
Accent Color: Lighter Green (#150 55% 50%) - Used for secondary elements and accents
Dark Background: Navy (#220 20% 10%)
Light Background: Off-white (#0 0% 96%)
Foreground Text: Dark gray (#220 15% 15%) in light mode, light gray (#0 0% 95%) in dark mode
Black: Used sparingly for emphasis (#0 0% 15%)
Borders: Subtle light borders with primary/accent colors at reduced opacity
Light & Dark Mode
Implement full dark mode toggle in header (Moon/Sun icon button)
Light mode: Clean white backgrounds with subtle color accents
Dark mode: Navy backgrounds with vibrant blue and green highlights
All colors adapt automatically based on dark class on root element

Headlines: Bold, dark gray/white (depending on mode)

Mobile-first approach

Tech Stack
Framework: React 18+ with TypeScript
Styling: Tailwind CSS with custom color variables
Routing: React Router v6
Icons: Lucide React
UI Components: shadcn/ui (Button, Card, Sheet, Toast)
Build Tool: Vite
Package Manager: npm/pnpm

Additional Notes
No complex animations, keep it professional and clean
Ensure proper contrast ratios for accessibility
Support for PDF file uploads (UI only, no backend needed)
All interactive elements should have hover states
Mobile-first responsive design
Maintain consistency in spacing (use Tailwind spacing scale)
